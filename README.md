## Общее описание
Проект представляет собой интерактивный генератор QR-кодов, реализованный на базе веб-технологий (HTML/JS). Приложение позволяет преобразовывать текстовые данные и ссылки в матричные коды с возможностью кастомизации цветовой схемы. В систему встроены инструменты проверки читаемости кода, сохранения истории последних запросов в локальное хранилище браузера и экспорт готового результата в формате графического изображения.

<br><br>

## Реализация

**Создание кьюаркода** <br>Процесс генерации базируется на библиотеке `qrcode.js`, которая преобразует входную строку в логическую матрицу данных. Для корректной обработки кириллицы и спецсимволов в скрипте используется предварительная кодировка через `unescape(encodeURIComponent(text))`. Отрисовка кода выполняется динамически: функция `generateQR` формирует HTML-таблицу, где каждой ячейке `<td>` присваивается цвет в зависимости от бинарного значения модуля в матрице. Такой подход позволяет избежать размытия при масштабировании, которое часто встречается у обычных изображений.

**Обработка цветов** <br>Техническая часть работы с цветом включает в себя не только визуальное изменение интерфейса, но и аналитический блок `checkContrast`. Система считывает HEX-значения из input-полей и рассчитывает относительную яркость (Luminance) для темного и светлого цветов. Если разница яркостей становится критически малой, скрипт выводит предупреждение о низком контрасте. Также реализован детектор инверсии: если цвет кода светлее фона, приложение уведомляет пользователя, что некоторые аппаратные сканеры могут не распознать такой QR-код.

**Работа с историей и хранилищем** <br>Для обеспечения постоянства данных между сессиями используется `localStorage`. При каждой успешной генерации функция `addToHistory` проверяет массив на дубликаты и сохраняет текст в локальную память браузера в формате JSON. Лимит истории ограничен пятью последними записями для оптимизации интерфейса. В блоке реализации также предусмотрен обработчик `renderHistory`, который вешает слушатели событий на элементы списка, позволяя восстановить текст в поле ввода и мгновенно перегенерировать код одним кликом.

**Скачивание файла** <br>Экспорт результата в графический файл реализован через асинхронную интеграцию с библиотекой `html2canvas`. Поскольку QR-код на странице представлен в виде таблицы, функция `downloadImage` делает его "скриншот" и перерисовывает содержимое на скрытый элемент `canvas`. После этого данные конвертируются в формат `Base64` с помощью метода `toDataURL()`. Программа автоматически создает временную гиперссылку с атрибутом `download`, имитируя нажатие пользователя, что позволяет сохранить итоговый PNG-файл напрямую в папку загрузок.

## Выводы

Разработка данного проекта позволила на практике освоить методы манипуляции DOM-структурой и интеграции внешних JavaScript-библиотек для решения прикладных задач. Реализованная система контроля контрастности и механизм работы с локальным хранилищем превращают простой конвертер в надежный инструмент с защитой от ошибок пользователя. Проект демонстрирует эффективность использования клиентских скриптов для создания быстрых и функциональных веб-инструментов без необходимости серверной обработки.
